## Referanse vs. Affiliate

### Kundereferanseprogram
- Referent er eksisterende kunde
- Engangs- eller begrensede belønninger
- Høyere tillit, lavere volum
- Best for: Produkter med naturlig jungeltelegraf

### Affiliateprogram
- Affiliater trenger ikke være kunder
- Løpende provisjonsforhold
- Høyere volum, variabel tillit
- Best for: Høy-ticket produkter, innholdsskapere

## Referanseloop

```
Trigger-Øyeblikk → Del-Handling → Konverter Referert → Belønn → (Loop)
```

### 1. Identifiser Trigger-Øyeblikker
**Høy-intensjon øyeblikk:**
- Rett etter første «aha-øyeblikk»
- Etter en vellykket oppgave
- Etter positiv interaksjon med support
- Ved naturlige delingspunkter

### 2. Insentivstruktur

| Modell | Eksempel | Best for |
|--------|----------|----------|
| Tosidig | Begge får kr 100 | B2C, bred adopsjon |
| Ensidig (referent) | Referent får kr 200 | B2B, færre men verdifulle |
| Ensidig (ny kunde) | Ny kunde får rabatt | Priselastisk marked |
| Kreditbasert | Begge får kr 100 i kreditt | SaaS, abonnement |
| Nivåbasert | Bedre belønning per referanse | Power-brukere |

### 3. Del-Mekanismer
- Personlig referanselenke
- E-post-invitasjon fra produktet
- Deling på sosiale medier
- Unik rabattkode

### 4. Friksjon i Deling
Minimer steg mellom «vil dele» og «har delt»:
- Forhåndsutfylt delingsmelding
- Kopier lenke med ett klikk
- Integrer i naturlige produktflyter

## Programoptimalisering

### Nøkkelmetrikker

| Metrikk | Formel | Benchmark |
|---------|--------|-----------|
| Deltakelsesrate | Delere / Totale kunder | 10–30% |
| Del-rate | Delinger per deltaker | 2–5 |
| Konverteringsrate | Nye kunder / Klikk på referanse | 5–15% |
| K-faktor | Invitasjoner × konvertering | >1 = viral |

### Vanlige Problemer

| Problem | Mulig årsak | Løsning |
|---------|-------------|---------|
| Lav deltakelse | Ingen vet om programmet | Promoter i produkt + e-post |
| Lav deling | For mye friksjon | Forenkel delingsprosessen |
| Lav konvertering | Svakt tilbud til ny kunde | Forbedre insentiv |
| Misbruk | Gaming av systemet | Valideringsregler |

## Norsk Kontekst

- **Jungeltelegraf:** Sterk kultur for anbefalinger i Norge
- **Tillit:** Nordmenn stoler på anbefalinger fra kjente
- **Insentiver:** Moderate insentiver fungerer (overdrevne virker mistenkelige)
- **Personvern:** GDPR gjelder — ikke del kontaktlister uten samtykke
- **Betaling:** Vipps for utbetaling av belønninger er forventet

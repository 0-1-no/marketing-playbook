## Anglisismer → norsk

Norsk markedstekst lekker engelsk. Det er ikke galt i seg selv — men når et godt norsk ord finnes, signaliserer anglisismen latskap og svekker troverdigheten. Bytt der norsk er like presist. Behold engelsk kun når det er etablert fagterm uten god norsk ekvivalent (f.eks. «SEO», «landing page» kan stå hvis BRAND.md/CONTENT-RULES.md tillater det).

| Anglisisme | Norsk |
|------------|-------|
| awareness (om merkevare) | kjennskap, oppmerksomhet |
| benefit | fordel, nytte |
| boost(e) | øke, løfte, styrke |
| customer journey | kundereise |
| deal | avtale, tilbud |
| engasjement (eng. *engagement*) | engasjement er greit; men «interaksjon»/«respons» er ofte mer presist |
| feature | funksjon, egenskap |
| feedback | tilbakemelding |
| insight | innsikt |
| leverage / leverage(r) | bruke, utnytte, dra nytte av |
| onboarding | oppstart, velkomstløp, igangkjøring |
| performance | resultat, ytelse, effekt |
| reach (rekkevidde) | rekkevidde |
| revenue | inntekt, omsetning |
| seamless / sømløs | smidig, problemfri, friksjonsfri |
| skille seg ut (eng. *stand out*) | bra norsk — behold |
| target(e) | rette mot, sikte på, målgruppe |
| timing | tidspunkt |
| touchpoint | kontaktpunkt |
| tweake | justere, finpusse |
| value proposition | verdiforslag, verditilbud |

> Vurder alltid mot BRAND.md «Words We Use/Avoid». Hvis merkevaren bevisst bruker engelske fagtermer (vanlig i tech/SaaS), ikke overstyr det — konsistens med den definerte stemmen vinner over en generell norsk-purisme.

## Byråkrat-/stivord → klart språk

Klarspråk-prinsippet (jf. Språkrådet og staten sin klarspråk-satsing): skriv som du snakker til én leser. Bytt tunge, formelle ord med hverdagsord. Dette løfter både lesbarhet og konvertering.

| Stivt / formelt | Klart |
|-----------------|-------|
| anvende | bruke |
| anskaffe | kjøpe, skaffe |
| benytte | bruke |
| bistå | hjelpe |
| dersom | hvis |
| eksempelvis | for eksempel |
| erholde | få |
| foreta | gjøre |
| forestå | stå for, lede |
| fremskaffe | skaffe, finne |
| henholdsvis | (ofte unødvendig — del setningen) |
| herunder | blant annet, deriblant |
| i forbindelse med | ved, for, om |
| i henhold til | etter, ifølge |
| i løpet av | på, innen |
| i relasjon til | om, til |
| implementere | innføre, sette opp, ta i bruk |
| inkludere | ta med, omfatte |
| medføre | føre til, gi |
| muliggjøre | gjøre mulig, la deg |
| omhandle | handle om, gjelde |
| oppnå | få, nå |
| samtlige | alle |
| tilrettelegge | legge til rette, gjøre enkelt |
| utgjøre | være, danne |
| vedrørende | om |
| å foreta en vurdering | å vurdere |
| å gi en anbefaling | å anbefale |

**Tommelfingerregel:** Nominaliseringer (verb gjort om til substantiv) gjør teksten treg. «Foreta en vurdering» → «vurdere». «Gi en anbefaling» → «anbefale». Finn ordene som ender på *-ing*, *-else*, *-asjon* og sjekk om et verb gjør jobben bedre.

## Fyllord og floskler å stryke

Disse tilfører sjelden noe. Stryk dem, eller erstatt med noe konkret. Hvert fyllord du fjerner gjør budskapet skarpere og respekterer leserens tid.

**Svake forsterkere (kutt):**
- veldig, virkelig, ekstremt, utrolig, kjempe-, super-
- helt, ganske, litt (når de utvanner et konkret poeng)

**Fyll (kutt):**
- egentlig, faktisk, i grunnen, liksom
- for å være helt ærlig
- som nevnt tidligere / som tidligere nevnt
- det skal sies at
- når sant skal sies
- i og for seg
- på mange måter

**Tomme åpninger (omskriv — gå rett på sak):**
- «I dagens digitale verden …»
- «I en stadig mer …verden»
- «Det er viktig å merke seg at …»
- «Mange bedrifter opplever at …»
- «Vi lever i en tid der …»

**Tomme avslutninger:**
- «For å oppsummere kort …»
- «Alt i alt kan vi si at …»
- «Avslutningsvis vil vi …»

## Buzzword-bingo (markedsfloskler)

Floskler som lyder imponerende men ikke betyr noe. De skaper mistillit fordi alle bruker dem. Bytt med et konkret utsagn leseren kan tro på.

| Flosk | Hva du heller gjør |
|-------|--------------------|
| revolusjonerende | vis hva som faktisk er nytt |
| banebrytende | samme — konkret forskjell |
| markedsledende | etter hvilken måling? oppgi kilde eller stryk |
| innovativ | beskriv det nye, ikke påstå det |
| sømløs(t) | beskriv hvor mange steg/klikk det faktisk tar |
| neste generasjon | hva er forskjellen fra forrige? |
| skreddersydd | for hvem, og hvordan? |
| verdensklasse | mot hvilken standard? |
| en gamechanger | hva endrer seg konkret for leseren? |
| best i klassen | etter hvilket kriterium? |

**Testen:** Hvis konkurrenten kan skrive nøyaktig samme setning om sitt produkt, sier den ingenting. Gjør den spesifikk eller stryk den.

## Full QA-sjekkliste

Bruk denne som siste kvalitetsport før du leverer redigert tekst tilbake. Den speiler editor-passene i SKILL.md.

### Før du starter
- [ ] Jeg vet hva teksten skal oppnå (mål + ønsket handling)
- [ ] Jeg vet hvem målgruppen er (sjekket JOURNEY.md ved tvil)
- [ ] Jeg har lest gjennom én gang uten å redigere

### Klarhet
- [ ] Hver setning er umiddelbart forståelig
- [ ] Ingen sjargong uten forklaring
- [ ] Pronomen har tydelig referanse («det», «dette» peker på noe konkret)
- [ ] Ingen setninger prøver å si for mye på én gang

### Flyt og kutt
- [ ] Fyllord fjernet (se liste over)
- [ ] Setningslengde varierer (bland korte og lange)
- [ ] Avsnitt er 2–4 setninger (web)
- [ ] Viktigste informasjon kommer først

### Aktiv stemme
- [ ] Passiv stemme byttet til aktiv der det styrker («Vi lager …» ikke «… blir laget»)
- [ ] Nominaliseringer byttet til verb («vurdere» ikke «foreta en vurdering»)

### Voice-konsistens (mot BRAND.md + CONTENT-RULES.md)
- [ ] Tonen matcher Tone of Voice
- [ ] Ingen ord fra «Words We Avoid»
- [ ] Terminologi fra «Words We Use» brukt konsistent
- [ ] Ingen anglisismer der norsk finnes (og merkevaren ikke bevisst bruker engelsk)
- [ ] Ingen utilsiktede toneskift (formell → kameratslig midtveis)

### So what (relevans)
- [ ] Hver funksjon kobles til en fordel for leseren
- [ ] Påstander svarer på «hva har jeg igjen for det?»
- [ ] Ingen imponerende-men-tomme utsagn

### Bevis
- [ ] Påstander er underbygget (tall, kilde, case)
- [ ] Sosialt bevis er konkret og attribuert
- [ ] Ingen ufortjente superlativer («markedsledende» uten kilde)

### Spesifisitet
- [ ] Vage ord byttet med konkrete (tall, tidsrom, eksempler)
- [ ] Generiske utsagn gjort spesifikke
- [ ] Filler-innhold fjernet

### Faktasjekk (særlig ved refresh)
- [ ] Alle årstall og statistikk oppdatert
- [ ] Påstander fortsatt sanne (pris, funksjoner, posisjonering)
- [ ] Lenker fungerer (ingen døde lenker)
- [ ] Ingen referanser til avviklede produkter/verktøy

### Sluttsjekk
- [ ] Ingen skrivefeil eller grammatikkfeil
- [ ] Konsekvent formatering (overskrifter, lister, bold)
- [ ] CTA er tydelig og handlingsorientert
- [ ] Kjernebudskapet er bevart gjennom alle endringer

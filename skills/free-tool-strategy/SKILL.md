# Free Tool Strategy

Du er en ekspert på «engineering as marketing» — å bruke gratis verktøy som vekstmotor. Målet er å planlegge og bygge verktøy som tiltrekker brukere, genererer leads og bygger backlinks organisk.

## Hvorfor gratis verktøy?

| Fordel | Mekanisme |
|--------|-----------|
| SEO | Verktøy-sider tiltrekker backlinks naturlig |
| Lead gen | E-post-capture for utvidede resultater |
| Merkevare | Daglig bruk = top of mind |
| Viralitet | «Prøv dette verktøyet» er lettere å dele enn «les denne artikkelen» |
| Kvalifisering | Brukere av verktøyet er allerede i målgruppen |

## 8-faktor Scorecard

Bruk dette for å evaluere om et verktøy er verdt å bygge. Gi 1–5 per faktor.

| Faktor | Spørsmål | Score |
|--------|----------|-------|
| **Søkevolum** | Er folk aktivt på jakt etter dette? | /5 |
| **Relevans** | Er brukerne i vår målgruppe? | /5 |
| **Differensiering** | Finnes det allerede? Er vårt bedre? | /5 |
| **Lead-kvalitet** | Vil brukerne ha kjøpskraft/behov? | /5 |
| **Byggekostnad** | Kan vi lage MVP på <40 timer? | /5 |
| **Vedlikehold** | Kreves det mye vedlikehold etter launch? | /5 |
| **Delbarhet** | Vil folk dele resultater/lenke til det? | /5 |
| **Backlink-potensial** | Vil andre nettsider lenke til det? | /5 |

**Terskel:** 25+ = Go. 20–24 = Kanskje. <20 = Skip.

## MVP Scope-sjekkliste

Bygg minst mulig for å teste markedet:

- [ ] Én kjernefunksjon (ikke feature-creep)
- [ ] Fungerer uten innlogging (friksjonsfritt)
- [ ] Mobilvennlig
- [ ] Resultater vises umiddelbart (ingen ventetid)
- [ ] Delbart resultat (unik URL eller screenshot-vennlig)
- [ ] E-post-capture for utvidede resultater (valgfritt, ikke påkrevd)
- [ ] SEO-optimalisert landingsside
- [ ] Open Graph meta for deling

## Gating-strategi

| Nivå | Hva bruker får | E-post-krav |
|------|---------------|-------------|
| **Åpent** | Grunnleggende resultat | Nei |
| **Soft gate** | Utvidet rapport | Valgfritt |
| **Hard gate** | Full analyse + historikk | Påkrevd |

**Anbefaling:** Start åpent, legg til soft gate for utvidede resultater. Hard gate dreper organisk vekst.

## Launch og Distribusjon

### Pre-launch
1. Soft-launch til eksisterende e-postliste
2. Samle feedback og fiks bugs
3. Forbered Product Hunt / Hacker News-innlegg

### Launch
4. Publiser på Product Hunt
5. Del i relevante communities (Reddit, LinkedIn)
6. Kontakt bloggere/journalister som skriver om bransjen
7. Submit til verktøy-kataloger

### Post-launch
8. Monitorer backlinks (Ahrefs)
9. Optimaliser landingsside basert på søkedata
10. Iterer basert på brukeratferd
